# MASS HOUSE - Investment and Property

Repositorio para la página web oficial de **MASS HOUSE Investment and Property SpA**, constructora e inmobiliaria especializada en soluciones habitacionales prefabricadas e industrializadas.

## Características del Proyecto
- **Diseño Estético:** "Construcción Pesada y Corporativa", inspirado en tipografías condensadas (Oswald), colores oscuros (`#0F0F11`) y acentos en naranja industrial (`#FF5722`).
- **Arquitectura:** Single-page landing con navegación fluida y animaciones de scroll.
- **Tecnologías:** HTML5, Tailwind CSS (vía CDN), AOS (Animate on Scroll).
- **Secciones:** Hero 3D, Grilla de Servicios (Tridente y Fábrica), Barra de Estadísticas, Modelos Base, Flujo de Pagos (Método) y Formulario de Contacto.

## Despliegue Rápido
Dado que el proyecto no requiere de dependencias de compilación ni servidores especiales, basta con abrir el archivo `index.html` en cualquier navegador web o alojarlo directamente en **GitHub Pages** de manera gratuita.

Para usar GitHub Pages:
1. Sube estos archivos a tu repositorio de GitHub.
2. Ve a los `Settings` (Ajustes) de tu repositorio.
3. En la barra lateral izquierda, selecciona `Pages`.
4. En "Source", selecciona la rama `main` y guarda.
5. ¡Listo! GitHub te dará una URL pública para compartir tu web.
